# audiblez

Converts an `.epub` or text-based `.pdf` into an `.m4b` audiobook with chapter markers, cover (EPUB) and
title/author metadata. Speech is generated by an OpenAI-compatible TTS server (by default the `phonon` model on the
user's Ollama Mac, roughly 50x faster than real time), or by Kokoro running locally.

## When to Use

- The user asks for an audiobook, or to "read", "narrate" or "convert to audio" a book, ebook, PDF, sermon or story.
- The user wants a story narrated with different voices for its characters.
- Not for scanned/image-only PDFs: there is no OCR. If `audiblez` reports 0 paragraphs, say the PDF has no text layer.

## Quick Reference

| Task | Command |
|---|---|
| Install / upgrade | `bash ${HERMES_SKILL_DIR}/scripts/install.sh "<tts_base_url>" "<tts_model>" "<voice>" "<llm_model>"` |
| List voices | `audiblez --list-voices` |
| Audiobook | `audiblez BOOK -o OUT` |
| Quick sample (first chapter only) | `audiblez BOOK -o OUT --max-chapters 1` |
| Specific voice / speed | `audiblez BOOK -o OUT -v "Hugh" -s 1.1` |
| Voice that fits the author (e.g. British male for Spurgeon) | `audiblez BOOK -o OUT --auto-narrator` |
| Character voices: detect cast | `audiblez BOOK -o OUT --characters` (writes `OUT/<stem>.cast.toml`, then stops) |
| Character voices: synthesize | run the same `--characters` command again |
| Character voices in one go | `audiblez BOOK -o OUT --characters --no-review` |
| Faster, without checking each clip | add `--no-verify` |
| Read footnotes too (they're skipped by default) | add `--no-skip-footnotes` |
| Keep Roman numerals as written (converted by default) | add `--no-roman-numerals` |
| Leave out Greek/Hebrew quotations (transliterated by default) | add `--foreign-scripts skip` |
| Use a cloud LLM for this run | add `--llm-model kimi-k3:cloud` |
| Article or web page saved as PDF: only title, author, date and body | `audiblez ARTICLE.pdf -o OUT --article` |
| Audition every voice | `audiblez --audition-voices -o OUT` |

`BOOK` is the path to the `.epub` or `.pdf`; `OUT` is a folder for this book, e.g. `{audiblez.output_dir}/<book name>`.
The result is `OUT/<stem>.m4b`, where `<stem>` is the book's file name without the extension.

## Procedure

1. **Install if needed.** If `audiblez --help` fails, or if `audiblez --help` doesn't mention `--characters`, run the
   install script with the configured values:
   `bash ${HERMES_SKILL_DIR}/scripts/install.sh "{audiblez.tts_base_url}" "{audiblez.tts_model}" "{audiblez.voice}" "{audiblez.llm_model}"`.
   It writes `~/.config/audiblez/config.toml` only if none exists. Edit that file to change providers later.
2. **Get the book onto disk** (download the user's link or save their attachment) in a folder of its own.
3. **Choose the mode.**
   - Default: plain narration in the configured voice.
   - Fiction with dialogue, or the user asks for character voices: use `--characters`.
   - Sermons, essays, classics by a known author: suggest `--auto-narrator`. It only switches voice when it is
     confident and a voice with the matching gender and accent is tagged in the config.
   - Don't use `--characters` on non-fiction: quotations there are mostly citations, not dialogue.
   - A news story, blog post, web page saved as PDF or other single article: use `--article`, which skips menus,
     ads, cookie notices, links, captions and reference lists, and opens with its title, author and date.
4. **Run it in the background**: a full book takes from minutes (phonon) to hours (Kokoro on CPU). Use a log:
   `mkdir -p OUT && nohup audiblez BOOK -o OUT [options] > OUT/audiblez.log 2>&1 &`
   Report progress from `tail -n 3 OUT/audiblez.log` (it prints `Progress: NN%` and an ETA) when the user asks.
5. **Character voices take two runs.** The first `--characters` run asks the LLM who speaks each quote, has it cast
   a voice for each character from the voice profiles (the `why` line says why), writes the cast sheet and stops.
   Review the cast as described in "Casting voices" below, show the user the cast table from the log (character,
   gender, lines, voice), and fix or change voices by editing the `voice = "..."` lines in `OUT/<stem>.cast.toml`.
   Then run the same command again. If the user asked for it all in one go, add `--no-review`.
6. **Deliver** `OUT/<stem>.m4b`. Once the m4b exists, the `OUT/<stem>_chapter_*.wav` files can be deleted to free
   space. Keep them while a run may be resumed: re-running skips chapters whose wav already exists.

## Casting voices

Every voice has a profile: `audiblez --list-voices` shows its gender, apparent age, accent, pitch and
expressiveness (how much the voice rises and falls; phonon voices range from about 2 to 6, higher is livelier).
Each character on the cast sheet has a gender, an age group, a `description` of their personality and way of
speaking, and a line count. When you review or change a cast, apply these rules in order:

1. **Gender** must match.
2. **Age**: match the character's age group to the voice's age. No phonon voice sounds like a child (the youngest
   are about 20 to 30), so children and teenagers get the youngest voices; elderly characters get the oldest
   (Edwin, Master Aldric, Sir Bramwell, Old Mortlake for men).
3. **Distinct main voices**: the characters with the most lines each get a voice nobody else uses, and two
   characters who talk to each other never share one. Minor characters (a few lines) may share voices.
4. **Temperament**: excitable, emotional, comic or lively characters get the most expressive voices; calm, dry,
   stern or reserved characters get steadier ones. Deep voices (low pitch) suit authority, gravity or menace.
5. **Accent**: everyone shares the accent of the book's setting (the narrator's accent is a good guide), except
   characters described as foreign. For a British book, use the British voices; for an American one, the American.
6. **Never** cast the narrator's voice, and use `style = "character"` voices (Azgorath, Grub the Ogre, Fairy
   Godmother, The Snow Queen, ...) only for creatures and fairy-tale figures of that kind.

If the user dislikes a voice, pick the next best voice by the same rules rather than any voice they haven't heard.
Changing voices on the cast sheet never re-runs speaker detection; only the audio is regenerated.

## Pitfalls

- **TTS server busy or unreachable**: the Ollama Mac also runs other models. Requests are retried, but a long
  queue can time out. Check with `audiblez --list-voices`. If `.local` doesn't resolve on this machine, use the
  Mac's IP address in `~/.config/audiblez/config.toml`.
- **Clip verification**: every clip is checked with a small speech recognizer (installed by the install script),
  and clips where the TTS model dropped, repeated or invented words are regenerated, in shorter pieces if retrying
  doesn't help. If the user hears a repeated or missing passage, check the log for `faster-whisper` warnings (the
  check wasn't running) or `keeping a clip that still has a problem` lines, which say which text failed. Lines like `TTS glitch (...)
  regenerating` in the log are this working, not an error. It roughly doubles the run time; `--no-verify` skips it.
- **Footnotes and Roman numerals**: footnotes are skipped and Roman numerals read as numbers by default. If the user
  hears a footnote read aloud, a numeral spelled out, or a word wrongly read as a number in a particular book, re-run
  that book with `--no-skip-footnotes` or `--no-roman-numerals` (or report the case so the rules can be fixed).
  Changing either setting regenerates the audio rather than reusing chapters made with the other setting.
- **Speed**: phonon only speaks at 1.0. Other speeds are applied when the m4b is made, which works fine.
- **Wrong chapters picked**: the log prints a table of all sections with ✅ on the selected ones. PDFs use their
  bookmarks, or larger-font headings when there are none. Front matter (cover, contents) is skipped. Long
  sections are split into "(part N)" pieces between paragraphs.
- **Character voices need voice profiles.** Ollama doesn't report gender, age or accent. The install script adds
  the measured phonon profiles from `references/phonon-voices.toml` to the config. For another TTS model, run
  `audiblez --profile-voices --update-config` after adding the profiling models to the install:
  `uv tool install --force --python 3.12 --torch-backend cpu --with faster-whisper --with speechbrain --with torchaudio
  git+https://github.com/Solife-me/audiblez` (about 1.5 GB of models are downloaded on first use). Without profiles, all characters are read by the narrator.
- **Re-casting**: editing the cast sheet automatically re-synthesizes the affected book (the wav names include a
  hash of the cast). To re-detect the characters, delete `OUT/<stem>.cast.toml` and `OUT/<stem>.speakers.json`.
- **Cloud LLM models** (`*:cloud`) use the user's Ollama cloud quota. Use them only when the user asks, or after
  asking first.

## Verification

- `ffprobe -v error -show_entries format=duration:chapter_tags=title -of compact OUT/<stem>.m4b` shows a duration
  and one chapter line per section.
- The log ends with `... .m4b created. Enjoy your audiobook.`
